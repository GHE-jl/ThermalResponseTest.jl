By topic

Data loading and pre-processing

  • TRTDataset — heating/recovery/full-test container
  • load_trt_data — read a TRT CSV into a DataFrame
  • decompose_trt — split into heating and recovery phases

Utilities

  • mean_fluid_temperature — p-linear mean of inlet/outlet temperature
  • centered_finite_difference, bourdet_derivative — dT/dt estimators
  • critical_time, residence_time — FOA validity-window helpers
  • step_signal — k-means segmentation of a variable-power signal

First-order approximation (Pasquier 2018)

  • fit_ils_foa_T — UFOA-T-H, temperature, heating phase
  • fit_ils_foa_T_recovery — UFOA-T-R, temperature, recovery phase
  • fit_ils_foa_dT — CFOA-Ṫ-H, temperature derivative, heating phase
  • fit_ils_foa_dT_recovery — CFOA-Ṫ-R, temperature derivative, recovery phase

Model inversion wrappers

  • fit_ground_response — generic core, any AbstractGroundModel
  • fit_ils — infinite line source
  • fit_ics — infinite cylindrical source
  • fit_fls — finite line source
  • fit_mils — moving infinite line source (groundwater advection)
  • fit_mfls — moving finite line source (groundwater advection)
